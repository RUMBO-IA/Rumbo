# RUMBO IA Launch Checklist V1

## Brand integrity
- [ ] First mention uses RUMBO IA.
- [ ] Core promise matches Messaging V1 or an approved variant.
- [ ] Colors/tokens match Brand System V1.
- [ ] Temporary R monogram is not presented as a registered mark.

## Claims
- [ ] Every material state/performance claim is classified BUILT/DEMO/PILOT/PRODUCTION/MEASURED.
- [ ] Demo data is labeled in the same context.
- [ ] Measured claims include method/window/source.
- [ ] No unsupported guarantees, absolute security or customer claims.

## Accessibility
- [ ] Keyboard focus is visible.
- [ ] Critical states have text/icon semantics beyond color.
- [ ] Contrast is checked for text and controls.
- [ ] Nonessential motion has a reduced-motion-safe path.

## Website
- [ ] Title and meta description align with canonical positioning.
- [ ] OpenGraph copy aligns with canonical positioning.
- [ ] CTA vocabulary is approved.
- [ ] Security/privacy links remain visible.
- [ ] Pilot/production wording matches current evidence.

## Distribution
- [ ] GitHub bio reviewed.
- [ ] LinkedIn copy reviewed.
- [ ] X bio reviewed.
- [ ] YouTube description reviewed.
- [ ] Marketplace description reviewed.
- [ ] Spanish/English terminology is consistent.

## Engineering gate
- [ ] Exact head SHA recorded.
- [ ] CI passes on exact head.
- [ ] Required review/thread rules pass.
- [ ] Brand release receipt records file digests.
- [ ] Publication authority recorded separately.
- [ ] Production deployment authority recorded separately if applicable.

No unchecked item may be silently represented as PASS.
