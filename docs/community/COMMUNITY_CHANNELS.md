# RUMBO community channels

RUMBO separates conversation from engineering authority.

## GitHub Issues

Use for reproducible bugs, scoped proposals, collaboration proposals, and work that can become an actionable engineering unit.

## GitHub Pull Requests

Use for reviewable source changes. A pull request is the evidence-bearing path for code integration.

## GitHub Discussions

When enabled, use for open-ended Q&A, announcements, ideas, showcases, and community conversations that are not yet scoped work.

A useful Discussion can be converted into or referenced by an Issue when it becomes actionable.

## Discord or another community chat

Discord may be used for community presence, office hours, peer help, events, and informal coordination.

Discord is not a source of truth for:
- repository permissions;
- approved requirements;
- security reports;
- secrets;
- canonical decisions;
- merge authority;
- deployment authority;
- production incidents containing private information.

Any decision that changes code, access, scope, or authority must be captured in the appropriate governed GitHub or private control-plane record.

## Security

Do not post undisclosed vulnerability details in community chat, public Issues, or Discussions. Follow `SECURITY.md`.

## Community moderation

Moderation may be delegated without source-write authority. For GitHub, prefer the Triage role when the duty is Issue, Discussion, and pull-request organization rather than code changes.
