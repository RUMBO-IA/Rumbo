# License position

Current state: this public repository does not publish an open-source license.

Therefore the repository must not be described as open source merely because its source is publicly visible. Public visibility and permission to use, copy, modify, or redistribute are separate questions.

Until an explicit license is selected, contribution and community materials should use the terms **public repository**, **public source surface**, or **Open Lab**, not make an unqualified open-source claim.

## Decision options

Before adding a LICENSE file, choose deliberately among:
- permissive open source, such as MIT;
- permissive open source with explicit patent terms, such as Apache-2.0;
- reciprocal/copyleft licensing;
- source-available or proprietary terms.

License selection is a legal/commercial policy decision and is not implied by accepting a pull request.

## Admission rule

No automation may add or change the repository license without an explicit owner-approved license identifier or approved license text.
