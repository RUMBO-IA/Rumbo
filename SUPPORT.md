# Support

RUMBO separates community help, product defects, security reports, and private operational support.

## Public questions

Use a GitHub Issue when the question is tied to a reproducible defect, a scoped change, or a concrete proposal.

GitHub Discussions is the preferred future home for open-ended Q&A, showcases, and community coordination once it is enabled for this repository.

## Security

Do not publish undisclosed security details in Issues, pull requests, chat, or Discussions.

Use the private vulnerability-reporting path described in `SECURITY.md`.

## Private operational matters

Customer data, credentials, internal control state, non-public provider details, and production incidents do not belong in this public repository.

## Response expectations

A report or proposal creates no commitment to accept, merge, deploy, fund, or support a change. Maintainers may close or redirect requests that are outside the public repository boundary.
