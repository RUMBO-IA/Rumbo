01 / Product support

One company, three bounded product areas.

Support is organized around the public RUMBO IA product pillars. A demo, source change, pilot, deployment, partner application or provider response is never treated as proof of another state.

Revenue Recovery

Support for controlled commercial workflows such as proposal follow-up, recovery and supervised next-action preparation.

Agent Reliability

Support for authority, state revalidation, execution, effect readback, evidence, retries, idempotency and recovery.

Guardian

Support for defensive assurance, least-privilege boundaries, policy enforcement and auditability within authorized scope.

02 / OpenAI-related integrations

Integration support without unsupported partnership claims.

RUMBO IA supports bounded integrations under explicit access and evidence requirements. A request, review, approval, listing and release are distinct states.

Human control

Consequential actions stay inside explicit authority and approval boundaries.

Effect verification

Tool or protocol success is not treated as proof that the intended external result occurred.

Evidence before claims

RUMBO IA does not claim OpenAI endorsement, approval, publication, Marketplace listing or Partner tier unless independently verified.

Data minimization

Do not send credentials, secrets or unnecessary sensitive data through support email. Use the minimum information required to reproduce the issue.

03 / Getting help

Send one reproducible issue at a time.

For faster triage, include the affected RUMBO IA product area, the expected outcome, the observed state, timestamps, the systems involved and any non-sensitive receipt or error identifier. Do not include passwords, API keys, recovery codes or private credentials.

Product / workflow

Describe the workflow, current state and expected observable result.

Reliability / execution

Include whether the action was attempted, what readback exists and whether the outcome remains unknown, partial or contradictory.

Security

Use only authorized defensive reports. See the Guardian / Security boundary before sharing sensitive technical details.

Privacy

For access, correction or deletion requests, use the corporate support address and reference only the minimum identifying information necessary.
