RUMBO IA · RUMBO CRM PRIVACY

Privacy for the bounded RUMBO CRM app.

This notice covers the public RUMBO CRM app and remote MCP surface used with OpenAI products, as well as this website and support contact.

01 / MCP data

What the bounded app processes.

RUMBO CRM processes only the values a user or ChatGPT submits to the four exposed tools. Depending on the requested tool, these values can include workspace identifiers, subject or lead identifiers, a note, current and proposed lead stages, an optional reason, an outreach channel, and an outreach objective.

The bounded public v1 does not expose customer-record search, contact retrieval, conversation search, analytics retrieval, CRM mutation, message sending, deployment authority, or publication authority.

The proposal tools return reviewable artifacts containing the submitted fields and explicit control metadata such as REVIEW_REQUIRED and side_effect=false. The outreach tool also returns send_authorized=false.

02 / Handling

Bounded processing and minimization.

RUMBO CRM does not sell submitted app data. The bounded MCP adapter does not persist submitted tool arguments to a CRM database and does not use them to perform external side effects. Technical hosting providers may process standard service logs such as IP address, request timestamps, response status, and runtime diagnostics for security and operation.

Users should avoid entering passwords, API keys, authentication tokens, payment-card details, private keys, seed phrases, or other secrets into RUMBO CRM tools or support requests.

03 / Website and support

Contact information.

If you contact RUMBO IA by email, the information you provide is used to respond to your inquiry and maintain necessary business records. It is not sold.

For privacy requests, contact sebastian@rumbo.verso.fans.
